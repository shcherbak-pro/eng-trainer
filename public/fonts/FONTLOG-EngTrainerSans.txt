FONTLOG for Eng Trainer Sans
============================

This file accompanies Eng Trainer Sans, the interface font of eng-trainer v2.

Eng Trainer Sans is a Modified Version of Source Sans 3 under the SIL Open Font
License, Version 1.1 (see OFL-EngTrainerSans.txt, which is the unchanged licence of
Source Sans 3 with its copyright and Reserved Font Name notice). It consists of four
web subsets of Source Sans 3 whose font names were changed, because the original
font reserves the name "Source" and a subset is a Modified Version.

Nothing else was changed. Glyph outlines, character mapping, OpenType shaping
features, metrics, the weight axis and its variation data, and all notices are
exactly those of the original files.

Source Sans 3 was designed by Paul D. Hunt at Adobe.
Copyright 2010-2020 Adobe (http://www.adobe.com/), with Reserved Font Name 'Source'.
Source is a trademark of Adobe in the United States and/or other countries.

Changes
-------

2026-11-22  Renamed for eng-trainer (ENG-V2-UX-01B-RC1).

The files contain only Windows naming records (platform 3, encoding 1, language
0x409). In each of the four files exactly these records changed:

  name ID 1 (family)
    before: Source Sans 3 ExtraLight
    after:  Eng Trainer Sans ExtraLight
  name ID 3 (unique identifier)
    before: 3.052;ADBO;Source Sans 3 ExtraLight-ExtraLight;ADOBE
    after:  3.052;ENGT;EngTrainerSans-Roman
  name ID 4 (full name)
    before: Source Sans 3
    after:  Eng Trainer Sans
  name ID 6 (PostScript name)
    before: SourceSans3-Roman
    after:  EngTrainerSans-Roman

Unchanged: name ID 0 (copyright, including the Reserved Font Name notice), 2, 5
(version), 14 (licence URL), 17, the axis, style and instance names 257 to 308, and
every other table (BASE, GDEF, GPOS, GSUB, HVAR, MVAR, OS/2, STAT, avar, cmap,
fvar, gasp, glyf, gvar, hhea, hmtx, loca, maxp, post, prep). In head only the
checksum adjustment differs, because it covers the whole file.

The WOFF2 files were compressed again, so their sizes differ from the originals by
a few dozen bytes. Decoded, each font is 24 bytes smaller: the shorter unique
identifier, less the longer family, full and PostScript names.

Preparation and reproduction
----------------------------

Tool: scripts/fonts/derive_eng_trainer_sans.py in the eng-trainer repository,
run with Python 3.14.7, fontTools 4.68.0 and brotli 1.2.1
(scripts/fonts/requirements.txt) in a separate virtual environment. The
application build does not run it and needs no font tooling.

  py -3.14 -m venv <environment>
  <environment>\Scripts\python -m pip install -r scripts/fonts/requirements.txt
  <environment>\Scripts\python scripts/fonts/derive_eng_trainer_sans.py --download --input-dir <originals> --output-dir <output>
  <environment>\Scripts\python scripts/fonts/derive_eng_trainer_sans.py --check --input-dir <originals> --output-dir <output>

The script refuses originals whose SHA-256 differs from the values above. The
output is deterministic: with the same tool versions it matches the output
hashes above. --check compares every decoded table of each original and its
derivative and fails on any difference other than the four name records and the
head checksum adjustment.
